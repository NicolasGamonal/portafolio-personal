CORRAL GOURMET

Menú digital interactivo para un restaurante de avena premium

Sobre el Proyecto

El Corral Gourmet es una aplicación web diseñada para que Don Juan administre su restaurante de avena premium con elegancia y eficiencia. Permite gestionar el menú, tomar pedidos, reservar mesas y visualizar estadísticas de ventas en tiempo real.

Cuenta con una interfaz moderna, responsiva y adaptada a dispositivos móviles, pensada para ofrecer una experiencia de usuario impecable tanto a clientes como al personal del restaurante.

Funcionalidades Principales

  • Menú digital con categorías y filtros (entradas, platos fuertes, postres).
  • Sistema de reservas de mesas con calendario interactivo.
  • Carrito de compras con cálculo automático de totales.
  • Panel de administración para gestionar productos y stock.
  • Diseño responsivo con Bootstrap 5.

Tecnologías Utilizadas

React Bootstrap 5 JavaScript (ES6) JSON
