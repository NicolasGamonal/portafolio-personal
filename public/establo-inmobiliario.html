ESTABLO INMOBILIARIO

Portal web para arrendar establos y cuadras de lujo

Sobre el Proyecto

Establo Inmobiliario es un portal web diseñado para conectar a propietarios de establos y cuadras de lujo con clientes que buscan el mejor espacio para sus caballos. Don Juan supervisa cada propiedad personalmente.

La plataforma permite publicar, buscar y filtrar propiedades según las necesidades específicas de cada cliente, con fichas detalladas, galería de imágenes y sistema de contacto directo con el propietario.

Funcionalidades Principales

  • Buscador avanzado con filtros por tamaño, ubicación y servicios.
  • Fichas detalladas de cada establo con fotos y planos.
  • Sistema de favoritos para guardar propiedades de interés.
  • Panel de administración para publicar nuevos establos.
  • Diseño responsivo optimizado para móviles y tablets.

Tecnologías Utilizadas

React JSON CSS3 Custom Properties Bootstrap 5
