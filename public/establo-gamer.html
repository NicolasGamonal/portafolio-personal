ESTABLO GAMER

Plataforma de videojuegos retro administrada por Don Juan

Sobre el Proyecto

El Establo Gamer es una plataforma interactiva donde Don Juan administra un catálogo completo de videojuegos retro. Incluye un sistema de gestión de stock, perfiles de jugadores y un carrito de compras con temática ecuestre única.

La aplicación combina lo mejor del mundo gamer con la elegancia del establo de Don Juan, ofreciendo una experiencia de usuario fluida, atractiva y completamente responsiva para todos los dispositivos.

Funcionalidades Principales

  • Catálogo de videojuegos retro con filtros por consola y género.
  • Sistema de perfiles de usuario con historial de compras.
  • Carrito de compras dinámico con temática ecuestre.
  • Panel de administración para gestionar stock y precios.
  • Diseño responsivo con Bootstrap 5 y Bootstrap Icons.

Tecnologías Utilizadas

React Bootstrap Icons Git / GitHub JavaScript (ES6)
